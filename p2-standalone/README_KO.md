# 느티나무 P2 독립 리모컨 장치 — 현장 시험용 0.1

**PC를 계속 켜 두지 않고 휴대폰의 노래 검색 결과를 P2로 보내기 위한 ESP32 프로그램입니다. 추가 장치가 필요하며, P2 / TIR-1090 실물 호환 시험은 아직 하지 않았습니다. 휴대폰과 P2의 블루투스만 연결하는 프로그램이 아닙니다.**

휴대폰의 기존 HTTPS 검색 화면 → 인터넷 중계 → ESP32 소형 장치 → 학습한 적외선 신호 → P2 순서로 동작하도록 작성했습니다. 초기 설치·프로그램 기록에는 USB 연결 PC와 장치 조립이 필요합니다. 설치 후 평소 운영에는 PC가 필요 없습니다. 아직 일반 손님에게 배포할 완제품이 아닙니다.

## 조사 결과와 남은 확인

- TJ 공식 사이트에서 블루투스는 휴대폰의 유튜브 소리를 반주기로 재생하는 용도로 설명합니다. 이것만으로 예약 제어가 된다고 볼 수 없습니다. [TJ 공식 안내](https://www.tjmedia.com/musicroom/song_room)
- 공식 TJ매니저는 반주기 연동에 Wi-Fi 동글이 필요하다고 안내합니다. 이 설명은 공식 앱에 대한 것이며, 자체 앱에서 쓸 수 있는 P2 제어 규격을 제공하지 않습니다. [TJ 공식 앱 안내](https://www.tjmedia.com/support/app)
- 공개 자료에서 P2의 블루투스 예약 규격이나 TIR-1090의 검증된 버튼별 코드를 찾지 못했습니다. 찾지 못했다는 것이 규격이 존재하지 않는다는 뜻은 아닙니다.
- 이 시험판은 실제 리모컨의 신호를 두 번 받아 비교하고 저장합니다. 숫자 0~9와 예약 버튼을 각각 시험하고, 연속 곡번호 예약까지 사람이 확인하기 전에는 손님 명령을 받지 않습니다.
- 기본 송신 주파수 38kHz는 시험값입니다. 수신 모듈은 반송 주파수를 측정하지 못하므로, TIR-1090에 맞는 주파수·수신기·반복 방식인지 현장에서 확인해야 합니다. 현재 상태에서 특정 판매 제품의 호환을 보증하거나 구매를 권하지 않습니다.

## 시험에 필요한 부품

| 부품 | 이 코드의 기준 |
|---|---|
| 제어 보드 | ESP32-WROOM-32 기반 ESP32 DevKit, PlatformIO `esp32dev`. ESP32-C3/S3용이 아닙니다. |
| 적외선 수신부 | 3.3V 논리 호환 복조 수신 모듈. 38kHz는 최초 시험 후보입니다. |
| 적외선 송신부 | 940nm IR LED와 전류 제한·트랜지스터 구동 회로가 포함된, 3.3V GPIO로 제어할 수 있는 모듈 |
| 전원 | 보드 사양에 맞는 안정적인 USB 5V 전원과 데이터 USB 케이블 |
| 학습용 리모컨 | 사용 중인 TIR-1090 |
| 네트워크 | 인터넷이 되는 2.4GHz 와이파이 |

수신부의 신호 출력은 GPIO27, 송신 구동부의 신호 입력은 GPIO26, GND는 공통으로 연결합니다. **모듈별 핀 순서는 다르므로 제품 표기를 확인해야 합니다. GPIO에 5V 출력을 넣거나 LED를 GPIO에 직접 연결하지 마세요.** 반주기 내부 배선은 건드리지 않습니다. 제작은 해당 회로를 다룰 수 있는 사람이 진행해야 합니다.

IR 라이브러리의 공식 [회로·사용 안내](https://github.com/crankyoldgit/IRremoteESP8266/wiki)와 [송신 예제](https://github.com/crankyoldgit/IRremoteESP8266/blob/v2.8.6/examples/IRsendDemo/IRsendDemo.ino)를 기준으로 작성했습니다. 신호가 다른 방의 반주기에 닿지 않도록 해당 P2 수신부를 향하게 배치하세요.

## 최초 설치 — 장치를 준비하는 사람용

1. Python과 PlatformIO를 사용할 수 있는 PC에서 이 폴더를 엽니다.
2. 아래 명령으로 설치·빌드합니다.

```sh
python -m pip install platformio==6.1.18 cryptography==45.0.7 certifi==2025.8.3
pio run
pio run -t upload
pio device monitor -b 115200
```

3. 장치가 처음 켜지면 시리얼 창에 `P2-Setup-...` 와이파이 이름과 무작위 설정 암호가 나옵니다. 암호를 장치 관리자만 보관하세요. 원격 제어용 비밀키는 표시하지 않습니다.
4. 관리자 휴대폰을 해당 와이파이에 연결하고 `http://192.168.4.1`을 직접 엽니다. ‘인터넷 없음’ 안내가 나오더라도 설정 중에는 해당 와이파이에 머무릅니다.
5. 매장 와이파이 이름과 암호를 저장합니다. 설정 화면에서 리모컨 버튼을 학습하고 실제 P2에서 시험합니다. 학습할 때 실제 리모컨 신호가 P2까지 함께 전달되지 않도록 주의하세요.
6. 숫자 0~9와 예약을 모두 확인한 뒤, 실제 수록 곡번호로 예약 시험을 합니다. 같은 숫자가 연속되는 곡번호도 시험하고, 한 번씩 정확히 예약되는지 확인합니다.
7. 확인 버튼을 누르고 8자리 연결번호를 적어 둡니다. 설정 종료를 누른 다음 휴대폰을 매장 와이파이 또는 모바일 데이터로 되돌립니다.
8. [기존 노래 검색 앱](https://cyberkjh36.github.io/neutinamu-song-search/)에서 해당 번호로 연결합니다. 검색한 곡을 선택하고 `이 곡 P2 예약`을 누릅니다. 연결번호를 포함한 손님 화면 링크도 설정 화면에서 확인할 수 있습니다.

8자리 번호는 **인터넷 중계 서버가 이 독립 장치에 발급하는 번호**입니다. P2 본체나 리모컨에 나오는 번호가 아닙니다. 기존 PC 연결번호와 별도이며, 장치 설정을 지우지 않으면 재부팅 후에도 같은 번호를 받습니다. 기존 웹 화면의 일부 안내에 ‘PC’라고 표시될 수 있습니다. 실제 연결 대상은 이 장치이며, 현재 운영 웹 화면을 변경하지 않고 같은 통신 규격을 사용합니다.

## 평소 사용

- 장치 전원과 매장 인터넷만 켜 둡니다. PC는 꺼도 됩니다.
- 안드로이드와 아이폰은 기존 HTTPS 검색 화면을 사용합니다. 별도 APK 설치 없이 작동하도록 구성했으나, 실물 휴대폰과 이 장치를 연결한 시험은 아직 하지 않았습니다.
- 휴대폰 5대 제한과 한 명령씩 순서대로 처리하는 방식은 기존 중계 서버의 규칙을 사용합니다.
- 시작·취소·일시정지·음정 버튼은 각각 학습 및 확인한 경우에만 사용 가능합니다. P2의 실제 버튼 기능과 같아야 합니다. 화면의 일시정지는 상태를 읽는 기능이 아니라 학습한 버튼 신호를 한 번 보내는 기능입니다.
- P2의 숫자 입력칸이 비어 있는 상태에서 사용하세요. 실제 리모컨으로 숫자를 입력하는 도중 휴대폰 예약을 함께 보내면 숫자가 섞일 수 있습니다. 이 장치는 P2 화면을 읽을 수 없습니다.

## 다시 설정하거나 전송을 재개하려면

장치가 켜진 상태에서 BOOT 버튼을 3초간 누르면 설정 와이파이가 열립니다. 설정 화면은 10분 후 닫히며, 설정 중에는 손님 조작을 중단합니다. BOOT 버튼을 누른 채 전원을 넣으면 다운로드 모드가 될 수 있으므로, 부팅이 끝난 뒤 누르세요.

전송 중 전원이 꺼지거나 저장 오류가 발생하면 확인되지 않은 신호를 자동으로 재전송하지 않습니다. P2의 숫자 입력칸과 예약 목록을 확인한 뒤 설정 화면의 ‘확인 후 재개’를 누릅니다. 저장 오류나 설정 손상은 자동으로 초기화하지 않으므로 기술자의 확인이 필요합니다.

## 검증 범위

자동 시험은 곡번호와 신호 순서, 같은 숫자 반복, 필요한 버튼 사전 확인, 만료 명령 거부, 전송 전 기록, 일부 전송 실패, 중복 요청 억제, 잘못된 입력 거부와 수신 길이 제한을 검사합니다. GitHub Actions는 ESP32 펌웨어 컴파일도 수행하도록 구성했습니다. 실제 실행 결과는 해당 커밋의 Actions 기록을 확인하세요.

**아직 검증하지 못한 항목:** P2/TIR-1090 실물 호환, 반송 주파수, 송신 거리·각도, 신호의 반복·토글 방식, 보드 전원 차단 시 동작, 현장 와이파이, 아이폰·안드로이드 5대 동시 연결. 이러한 현장 시험을 통과해야 손님용으로 사용할 수 있습니다.

핵심 처리 시험:

```sh
g++ -std=c++17 -Wall -Wextra -Werror -Iinclude tests/core_test.cpp -o test-core
./test-core
```

## 파일 구성

- `src/main.cpp`: 장치 설정, 신호 학습·송신, 영구 연결 정보, HTTPS 중계
- `include/command_core.h`: 명령 검증, 예약 순서, 중복 전송 방지
- `include/setup_page.h`: 휴대폰에서 여는 장치 관리자 화면
- `tests/core_test.cpp`: 실제 명령 처리 함수의 자동 시험
- `make_ca_bundle.py`: Mozilla 신뢰 인증서를 ESP32용으로 변환. 인증서 검증을 끄는 우회는 사용하지 않습니다.
- `platformio.ini`: 고정된 보드·라이브러리 빌드 설정

기존 PC용 BroadLink 시험 도구와 신호 파일 형식은 다릅니다. 이 장치에서는 리모컨을 새로 학습해야 합니다. 기존 PC 프로그램과 `/wk/` 유튜브 기능, 애창곡 데이터는 수정하지 않습니다.
