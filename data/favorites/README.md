# 느티나무 노래방 · 통합 애창곡

업데이트한 WorldKaraoke PC 런처가 실제로 재생한 영상의 기록을 합산합니다.
유튜브 전체 조회 수나 손님의 노래 부르는 소리를 집계하는 기능은 아닙니다.

- `all.json`: 모든 국가의 영상별 재생 횟수
- `ko.json`, `th.json`, `fil.json`, `vi.json` 등: 국가별 목록
- `und.json`: 아직 국가가 지정되지 않은 수집 기록

각 목록은 **재생 횟수가 많은 영상부터** 정렬됩니다. 같은 영상도 선택한
국가가 다르면 별도로 집계합니다. 기존 기록을 여러 PC에서 가져오거나
전송을 재시도해도 원래 출처가 같은 횟수는 중복으로 더하지 않습니다.
수집 확장 프로그램 기록을 재분류하면 같은 횟수가 새 국가로 이동합니다.

PC 런처는 인터넷 연결 시 약 30초 간격으로 공유 집계 서버와 동기화합니다.
오프라인에서 쌓인 기록은 PC에 유지되며 다음 연결 때 전송됩니다. 휴대폰의
애창곡 화면도 연결된 PC의 통합 목록을 사용합니다. 설치한 PC가 꺼져 있는
동안에는 새 재생 기록이 생기지 않지만, 이미 전송한 기록은 유지됩니다.

GitHub Actions가 매시간 7·22·37·52분(UTC)에 집계 결과를 자동 저장합니다.
GitHub 상황에 따라 실행이 늦어질 수 있습니다. GitHub 파일 갱신을 기다리지
않아도 PC 간 목록은 집계 서버를 통해 갱신됩니다. 작업 상태는 저장소의
**Actions → Save shared karaoke favorites**에서 확인할 수 있습니다.

GitHub에는 영상 ID·제목·주소·국가·횟수·마지막 재생 시각만 저장합니다.
PC 이름, 손님 정보, 연결번호, 인증키, 내부 출처 ID는 공개 파일에 넣지 않습니다.
런처용 쓰기 인증키는 GitHub 토큰이 아니며 암호화된 설치파일로만 배포합니다.
사이트 환경 변수 `WK_FAVORITES_WRITE_KEY`와 일치해야 합니다.

GitHub Actions가 서버 오류나 재생 합계 감소를 감지하면 이전 파일을
덮어쓰지 않고 실패로 표시합니다. 60일 이상 저장소 활동이 없는 공개
저장소에서는 예약 작업이 중지될 수 있으며, Actions에서 다시 활성화할 수
있습니다. GitHub에 저장된 JSON은 공개 집계 백업이며, 출처별 중복 제거
정보가 필요한 기존 `.wkstats.json` 내보내기 파일과는 형식이 다릅니다.

기존 PC의 로컬 기록은 자동으로 삭제하지 않습니다. PC 간 수동 백업·복원에는
런처의 기존 애창곡 내보내기/가져오기 기능을 계속 사용하세요.
