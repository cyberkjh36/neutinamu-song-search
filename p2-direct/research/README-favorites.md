# 추천 애창곡 자료 — 2026-11-09

0.11.13은 30~40대 애창곡 50곡, 50~60대 애창곡 50곡, 트로트 베스트 50곡을 포함한다. 항목 사이의 중복을 제외하면 128곡이다.

출처: [TJ미디어 TOP100](https://www.tjmedia.com/chart/top100).
공개 차트 페이지가 사용하는 `/legacy/api/topAndHot100` 조회에서 2026-10-01~2026-10-31, 종합/발라드/댄스/트로트/포크 결과를 2026-11-09에 확인했다. 이 폴더의 JSON에는 선택곡의 사실 정보인 곡번호·제목·가수·원래 장르 내 순위만 보관했다.

- 연령별 두 목록은 현재 인기차트에 있는 곡 중 익숙한 발라드·댄스·추억의 가요를 편집하여 고른 **추천곡**이다. 연령별 공식 집계, 매장 사용 통계, 실시간 순위를 뜻하지 않는다.
- 트로트 목록은 같은 기간 TJ 트로트 장르 차트 1~50위 곡이다. 장르 분류는 TJ의 분류를 따른다.
- 표시할 제목·가수·곡번호는 앱의 기존 두 CSV에 있는 정확한 레코드와 대조했다. 가사, 음원, 앨범 사진은 포함하지 않는다.
- 각 곡의 `evidence`는 이 폴더의 차트 종류와 순위로 연결된다. 테스트에서 모든 항목을 검증한다.
- 자료는 앱에 내장된다. 자동 갱신을 주장하지 않으며, 앱 내 선곡 기준에 조회 기간과 확인일을 표시한다.

아이콘 → 목록 → 곡 선택은 기존 검색의 정확한 곡번호 조회로 연결된다. 실행/예약은 기존 버튼을 명시적으로 눌러야 한다. 반주기 통신, 방 매핑, 예약 순서와 제어 명령은 변경하지 않았다.
