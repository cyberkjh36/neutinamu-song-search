# P2 연결진단 시험판 0.3

사용자가 제공한 2026-11-06 PCAP와 **10909번 실행·취소 조작 확인**을 바탕으로 만든 안드로이드 실험용 앱입니다. PC, IR 중계기, 8자리 중계 연결번호를 사용하지 않습니다. 기존 웹앱과 `/wk/`는 변경하지 않았습니다.

**실제 P2에서 곡 실행은 아직 성공하지 않았습니다.** 0.2에서는 P2 TCP 접속 뒤 `3000 / 길이 4 / 값 3003`을 받았고 앱이 연결을 닫았습니다. TJ매니저 강제 중지 후에는 P2 네트워크 경로가 사라져 `N10`이 기록되었으며 사용자가 강제 중지 뒤 시험한 결과임을 확인했습니다. `3003`의 의미는 아직 모릅니다.

## 0.3 수정 사항

- 공개 Android `WifiP2pManager.initialize()`로 시험 앱도 Wi-Fi Direct 사용 앱으로 등록합니다. TJ매니저 설정으로 이동하는 `onPause`/`onStop` 동안 등록을 유지하고 시험 화면을 종료할 때 해제합니다.
- 연결 상태 조회, 권한 거부, 응답 지연, 채널 종료를 별도로 표시합니다. Android 10의 비지속적 연결 방송을 기다리기만 하지 않고 돌아올 때 현재 연결 정보를 다시 조회합니다.
- `① 직접 Wi-Fi 연결 준비 → ② TJ매니저 설정 열기 → ③ P2 연결 시험` 순서를 제공합니다. ②는 등록과 현재 연결 주소가 확인된 뒤에만 진행할 수 있고 누르는 순간 다시 확인합니다. 다른 앱을 자동으로 종료하지 않습니다.
- **사용 앱 등록, 무선 연결 확인, 반주기 초기 응답 확인, 실제 곡 재생은 서로 다릅니다.** 등록만으로 연결 유지나 인증 성공을 표시하지 않습니다. 상태 조회의 주소 일치는 기기 인증을 대신하지 않으며 TCP 연결 뒤 기존 기기 식별 비교를 그대로 수행합니다.
- `N10` 안내를 연결 경로 부재로 구분했습니다. `3003`은 성공으로 간주하지 않으며 인증값/명령 내용을 추측하여 변경하지 않습니다.
- **P2 연결진단 0.3**이라는 별도 아이콘으로 설치합니다. 기존 진단판의 임시 서명키를 보관하지 않아 패키지명도 구분합니다. 기존 웹앱, WorldKaraoke, TJ매니저의 파일과 설정은 변경하지 않습니다.
- 개인정보 없는 진단 공유, 오프라인 검색, 시작·취소 버튼 안내 등 0.2 기능은 유지합니다.

이 변경은 Android 공개 소스에서 마지막 Wi-Fi P2P 클라이언트가 종료되면 그룹과 인터페이스를 정리하는 동작을 근거로 합니다. 삼성 펌웨어 및 P2에서 연결 유지가 되는지는 별도 실기 시험이 필요합니다. 새 NFC/Wi-Fi 연결을 스스로 만드는 기능이나 독립 로그인 구현은 아닙니다.

## 구현 범위

- 기존 저장소 곡 목록을 앱에 포함해 제목·가수·곡번호로 검색합니다. 입력 중 자동 실행하지 않습니다.
- PCAPdroid 파일에서 초기 연결 메시지와 해당 P2 식별값만 메모리로 불러옵니다. 원본 파일·개인정보·비밀번호를 서버로 업로드하지 않습니다.
- 이미 연결된 P2의 로컬 Wi-Fi 경로를 사용해 TCP 7070에 연결합니다.
- 초기 응답 뒤 기기 식별값을 비교하고, 일치하는 경우에만 시작·취소 명령을 전송합니다. 연결 전 버튼을 누르면 연결 안내를 보여 줍니다.
- 사용자가 시작을 누르면 곡번호를 전송하고, 취소를 누르면 확인된 취소 명령을 전송합니다.
- TCP 분할·합쳐진 패킷, 연결 유지 응답, 중복 클릭, 응답 시간 초과, 연결 종료를 처리합니다.
- 시작 요청 응답만으로 재생 성공을 표시하지 않습니다. 일치하는 4300 곡번호 메시지를 받아야 재생 상태 수신으로 표시합니다. 화면·소리 확인은 별도로 필요합니다.
- 명령을 자동으로 재전송하지 않습니다.

## 시험 순서 (같은 안드로이드 휴대폰·같은 P2)

1. `P2 연결진단 0.3`을 설치합니다. 기존 `P2 연결진단`과 아이콘 이름이 다릅니다.
2. TJ매니저에서 평소처럼 NFC로 P2에 연결하고 홈 버튼으로 나옵니다. 아직 TJ매니저를 강제 중지하지 마세요. PCAPdroid 캡처는 중지합니다.
3. **P2 연결진단 0.3**에서 **내 PCAP 연결 기록 선택**으로 기존 `.pcap` 파일을 선택합니다.
4. **① 직접 Wi-Fi 연결 준비**를 누릅니다. 권한 요청이 나오면 허용합니다. Android 12 이하에서는 위치 권한, 13 이상에서는 근처 기기 권한을 사용합니다. 위치 데이터를 수집하지 않습니다.
5. **[W01] 직접 Wi-Fi 연결과 앱 등록을 확인했습니다**가 나온 경우에만 **② TJ매니저 설정 열기**를 누릅니다. 열린 TJ매니저 설정에서 **강제 중지**를 누른 뒤 뒤로 돌아옵니다. **시험 앱 자체를 종료하지 마세요.**
6. 돌아와 **[W01] 설정에서 돌아온 뒤에도 직접 Wi-Fi 연결이 확인됩니다**가 나오면 **③ P2 연결 시험**을 누릅니다. W02/W04/W05/W06 또는 N10이면 반복 종료하지 말고 **진단 결과 공유 → ChatGPT**로 결과를 보냅니다.
7. 반주기 초기 응답과 식별 확인이 완료된 경우에만 `10909`를 선택해 **선택한 곡 시작**, 실제 P2 화면·소리를 확인한 뒤 **현재 곡 취소**를 시험합니다. A01/3003이면 아직 연결 절차가 완료되지 않은 것으로 결과를 공유합니다.

②에서 설정을 자동으로 열지 못하면 **휴대폰 설정 → 애플리케이션 → TJ매니저(업주용)**으로 이동할 수 있습니다. 이 경우에도 먼저 ①에서 W01 확인이 필요합니다. 매장 공유기나 반주기 설정을 변경할 필요는 없습니다.

시험 앱의 Activity가 종료되거나 OS가 프로세스를 정리하면 등록이 해제됩니다. 등록 유지가 제조사의 네트워크 정리나 P2 측 종료를 막는다고 보장할 수 없습니다. 연결이 끊어졌으면 TJ매니저에서 평소 NFC 방식으로 복구하세요.

## 남은 확인 사항

- 초기 연결 메시지의 식별자 필드 및 불명확한 헤더 값의 의미, 새 세션에서의 재사용 가능 여부.
- 동일 연결에서 두 번째 곡·여러 곡 연속 실행. 한 곡의 캡처만으로 헤더가 고정값이라고 단정할 수 없습니다.
- 공식 앱 없이 새 Wi-Fi/NFC 연결을 만드는 과정.
- iPhone 연결 방식 및 네이티브 앱 배포. 안드로이드 시험 결과를 아이폰 동작 보장으로 해석하면 안 됩니다.
- 예약·우선예약·음정·템포 등 기록에서 확인하지 않은 명령은 구현하지 않았습니다.

## 검증과 빌드

Java 17, Gradle 8.11.1, Android SDK 35, AGP 8.9.2:

```sh
gradle -p p2-direct :core:test :core:jar :app:testDebugUnitTest :app:assembleDebug :app:lintDebug
```

PR의 `P2 direct Android trial` workflow가 단위 테스트, APK 빌드, Android lint, 포함된 두 곡 목록 파일을 확인합니다. 프로토콜 테스트는 모의 TCP 서버, 화면 테스트는 Robolectric의 Android 9·10·15 환경입니다. 물리 P2나 실제 휴대폰 검증과 다릅니다.

로컬 원본 PCAP를 외부 전송하지 않고 가져오기 기능만 확인:

```sh
java -cp p2-direct/core/build/libs/core.jar kr.neutinamu.p2.Inspect /private/path/capture.pcap
```

PCAP 가져오기는 little-endian classic PCAP, raw IPv4/TCP, 로컬 기기 7070 흐름을 지원합니다. PCAPNG, IP 단편, TCP 시퀀스 wraparound, 일부만 겹치는 재전송은 지원하지 않습니다. 누락된 기록이나 서로 다른 여러 기기의 기록은 거부합니다. 원본 PCAP나 인증값을 커밋하지 마세요.

참고: [Chrome Direct Sockets 제한](https://developer.chrome.com/docs/iwa/direct-sockets), [Android Wi-Fi Direct](https://developer.android.com/develop/connectivity/wifi/wifip2p).

연결 유지 근거: [Android Wi-Fi P2P 서비스의 마지막 클라이언트 정리](https://android.googlesource.com/platform/frameworks/opt/net/wifi/+/a8d5e40/service/java/com/android/server/wifi/p2p/WifiP2pServiceImpl.java), [Channel 수명과 close](https://developer.android.com/reference/android/net/wifi/p2p/WifiP2pManager.Channel).
