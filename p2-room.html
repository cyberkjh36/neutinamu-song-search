연결 후 노래를 시작하세요

  1. 앱 열기 또는 Wi-Fi 연결 확인 창이 나오면 허용해 주세요.
  2. 앱에 방번호와 ‘연결됨’이 표시될 때까지 기다려 주세요.
  3. 음성·키보드·한글 초성으로 노래를 찾고, 곡을 선택한 뒤 곡 시작을 누르세요.

안드로이드 앱 0.9.0부터 방 QR로 연결을 시작할 때 연결 기록 파일을 선택하지 않아도 됩니다. Wi-Fi를 켜고 처음 나오는 권한·연결 확인 창을 허용해 주세요. 연결되지 않으면 직원에게 문의해 주세요. 앱이 설치되어 있어야 합니다.

아이폰과 일반 웹 화면의 P2 직접 제어는 현재 지원하지 않습니다.
