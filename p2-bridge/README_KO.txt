느티나무 P2 휴대폰 연결 · 0.2
2026.11.06

무엇이 달라졌나요?
기존 ‘노래방 노래검색’ 웹앱에서 찾은 곡을 P2 예약 신호로 보낼 수 있도록 연결했습니다.
휴대폰 주소: https://cyberkjh36.github.io/neutinamu-song-search/
별도의 휴대폰 APK는 설치하지 않습니다. Android Chrome / iPhone Safari에서 여세요.
YouTube WorldKaraoke 런처와 별개의 P2 반주기용 기능입니다.

먼저 알아둘 점
이것은 소프트웨어 검사를 마친 현장 시험용 연결 도구입니다.
실제 TJ P2 + TIR-1090 + RM4 mini 조합은 이 개발 환경에서 시험하지 못했습니다.
P2 실물에서 학습·예약 시험에 성공하기 전에는 손님용으로 켜지 마세요.
블루투스만 연결해서 P2가 조작되는 프로그램이 아닙니다.
RM4 mini는 시험 후보이며 P2와의 호환성을 보증하지 않습니다.
실제 리모컨 신호가 하나도 들어 있지 않습니다. 시험용 가짜 신호는 프로그램에서 사용하지 않습니다.

준비물
- 인터넷에 연결된 Windows PC, Python 3.10 이상(공식 python.org 배포판, Tk 포함)
- 실제 P2 반주기와 작동하는 리모컨
- 적외선 신호 학습·전송 장치: BroadLink RM4 mini 시험 후보
- 같은 공유기에 연결된 PC와 송신 장치(PC는 유선 LAN 가능, RM4 mini는 2.4GHz Wi-Fi)
- Android 또는 iPhone
휴대폰은 인터넷이 연결되면 됩니다. 송신 장치 앞과 P2 수신부 사이를 가리지 마세요.

PC 준비
1. ZIP을 풀고 1_install_dependencies.cmd를 실행합니다.
   Python과 인터넷이 필요합니다. 공식 PyPI에서 broadlink 0.19.0, qrcode 8.2를 설치합니다.
2. 2_start_test.cmd를 실행합니다.
3. BroadLink 공식 앱에서 장치를 공유기에 연결합니다.
   PC 제어가 막혀 있다면 공식 안내에 따라 장치의 로컬 제어 잠금 여부를 확인합니다.
4. 공유기 또는 공식 앱에서 확인한 장치의 내부 IP를 입력하고 ‘장치 연결’을 누릅니다.
   다른 PC나 반주기의 IP가 아니라 RM4 mini의 IP입니다.
5. 숫자 0~9와 예약 버튼을 각각 선택하여 ‘선택 버튼 학습’을 누릅니다.
   장치가 학습 대기 상태가 되면 실제 리모컨의 해당 버튼을 짧게 한 번 누릅니다.
6. ‘선택 버튼 시험’으로 모든 숫자가 한 번씩 정확히 입력되는지 확인합니다.
   ‘이 곡 예약 시험’으로 곡번호와 예약 동작도 확인합니다. 시험 전 숫자 입력칸을 비우세요.
   시작·일시정지·취소·음정 버튼도 사용하려면 각각 학습하고 실제 동작을 시험하세요.
   학습한 파형 자체에 반복이 포함될 수 있으므로 중복 입력 여부를 꼭 확인하세요.
7. ‘P2 휴대폰 연결 / QR’을 누릅니다.
   ‘P2에서 시험 완료 · 휴대폰 연결 시작’을 누르고 시험 여부를 확인합니다.
8. QR과 8자리 번호가 표시됩니다. PC 프로그램은 실행 상태로 두세요.

손님 사용 순서
1. PC 연결 창의 QR을 휴대폰 카메라로 찍습니다.
2. 노래검색 화면의 연결번호가 채워져 있는지 확인하고 ‘P2 연결’을 누릅니다.
   QR을 사용하지 않았다면 PC에 나온 P2 연결번호 8자리를 직접 입력합니다.
3. 제목 또는 가수를 입력하고 검색하거나, 마이크 버튼으로 제목을 말합니다.
4. 검색 결과에서 원하는 곡·가수를 확인합니다.
5. 큰 곡번호 아래 ‘＋ 이 곡 P2 예약’을 누릅니다.
6. ‘송신 장치가 응답했습니다’가 나오면 P2 화면의 예약 목록을 확인합니다.
   이 문구는 적외선 송신 장치의 응답이며 반주기의 예약 성공 확인은 아닙니다.
7. 필요하면 연결 패널에서 시작·일시정지·취소·음정 버튼을 사용합니다.
   신호를 학습하지 않은 버튼은 사용할 수 없습니다.

연결 유지
- QR 창의 X를 누르면 창만 숨깁니다. 연결번호와 휴대폰 연결은 유지됩니다.
- 메인 창의 ‘P2 휴대폰 연결 / QR’을 다시 누르면 같은 창이 나타납니다.
- PC 프로그램을 종료하면 연결이 중단됩니다. 다시 실행해도 같은 연결번호를 사용합니다.
- PC에서 중지/시작한 뒤 휴대폰 연결이 만료되었다면 ‘P2 연결’을 다시 누릅니다.
- 최대 5대가 연결됩니다. 사용하지 않는 휴대폰은 ‘연결 해제’를 누르세요.
- 연결번호는 이 PC의 설정이 유지되는 동안 같습니다. 설정 파일을 지우거나 다른 PC로 옮기면 달라질 수 있습니다.
- PC 이름은 기본 ‘느티나무 P2’입니다. 다른 방은 각각 다른 PC 설정과 송신 장치를 사용하세요.

전송 문제 안내
- 오래된 명령은 나중에 갑자기 실행되지 않도록 약 15초 후 만료됩니다.
- 응답이 끊긴 명령은 중복 예약 방지를 위해 자동 재전송하지 않습니다.
- ‘전송 결과를 확인할 수 없습니다’일 때는 먼저 P2 예약 목록을 확인하세요.
- 숫자 전송 도중 오류가 나면 휴대폰 조작을 중단합니다.
  P2 입력칸과 예약 목록을 확인하고 입력 중인 숫자를 지운 뒤 ‘P2 화면 확인 후 재개’를 누르세요.
- 휴대폰 조작 중에는 PC 신호 학습/개별 시험을 잠급니다.
  신호를 다시 학습하려면 휴대폰 연결을 중지하세요. 변경 후에는 다시 실물 시험을 확인해야 합니다.
- 손님들이 기존 리모컨으로 숫자를 입력하는 중에 앱으로 곡을 예약하면 번호가 섞일 수 있습니다.
  앱은 P2 화면을 읽을 수 없으므로 동시 입력은 피하세요.
- QR 번호를 아는 사람이 작동 중인 장치에 연결할 수 있습니다. 매장 손님에게만 보여 주세요.

이 파일들을 손님이나 공개 GitHub에 올리지 마세요.
PC 동시 실행을 막기 위해 같은 설정으로 프로그램 하나만 실행할 수 있습니다.
