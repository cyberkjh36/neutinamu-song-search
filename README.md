# 느티나무 노래찾기

https://cyberkjh36.github.io/neutinamu-song-search/

아이폰 Safari와 안드로이드 Chrome에서 별도의 APK 없이 노래 제목·가수·곡번호를 검색하는 웹앱입니다. 기존 QR 주소를 그대로 사용합니다.

## 홈 화면 아이콘

- 아이폰: 사이트의 ‘아이폰 홈 화면에 추가’를 눌러 안내를 확인합니다. Safari의 공유 → 홈 화면에 추가 → 추가를 누릅니다. ‘웹 앱으로 열기’가 있으면 켭니다.
- 안드로이드: ‘홈 화면에 아이콘 추가’를 누르고 브라우저의 추가 안내를 완료합니다. 안내만 나오면 Chrome의 ⋮ → 홈 화면에 추가 또는 앱 설치를 이용합니다.
- 구형 갤럭시: 안내의 ‘바로가기 모드’나 삼성 인터넷의 현재 페이지 추가 → 홈 화면을 이용할 수 있습니다.

웹페이지가 사용자의 확인 없이 아이콘을 만들 수는 없습니다. 첫 추가 후에는 홈 화면의 마이크 아이콘으로 실행합니다. 기존 아이콘과 앱 ID·주소는 유지합니다.

## 검색

제목과 가수의 한글 초성, 완성형 글자를 섞어 검색할 수 있습니다. 예: `ㅈㅇㅍ 꿈`, `이ㅁㅅ ㄱㄹㅅ`, `ㄱㄹㅅㄱㄴㅇㄹㅅㅁ`. 검색 버튼 또는 글자 조합이 끝난 뒤 Enter로 검색합니다. 76,617곡의 기존 목록 및 개인 CSV 가져오기·내보내기를 유지합니다. 한 번 준비한 목록은 인터넷 없이도 글자로 검색할 수 있습니다.

음성 검색은 브라우저·운영체제의 지원, 마이크 권한 및 네트워크 상태에 영향을 받습니다. 지원되지 않는 아이폰에서는 입력칸을 누르고 키보드의 받아쓰기를 이용합니다. 실제 음성 인식과 홈 화면 추가는 휴대폰에서 확인해야 합니다.

## P2 연결 범위

이 GitHub Pages 웹앱의 기본 기능은 노래 번호 검색입니다. 찾은 번호를 반주기 리모컨에 입력합니다. 일반 모바일 브라우저는 기존 P2 직접 제어에 필요한 원시 소켓/Wi-Fi Direct 인터페이스를 제공하지 않으므로 안드로이드 직접 제어 APK를 웹앱으로 바꾸어 동일하게 실행할 수 없습니다.

사용자가 확인한 직접 연결은 안드로이드 앱의 **주변 P2 찾기 → 반주기 선택 → 직접 Wi-Fi 연결 → 노래 실행·취소** 방식입니다. PC 또는 중계용 휴대폰을 사용하는 방식이 아닙니다. 통합 앱 0.7의 **P2 연결·설정**에서 기존 직접 연결 화면으로 이동할 수 있습니다.

v16에서는 이 흐름과 혼동되는 PC 중계 연결, 8자리 연결번호, 예약/리모컨 버튼을 웹 화면에서 제거하고 관련 모듈·스타일을 로드하거나 미리 저장하지 않습니다. 웹 검색과 홈 화면 아이콘만 제공하며, 직접 연결을 웹브라우저에 구현했다고 주장하지 않습니다. 이전 직접연결 APK의 통신 코드와 WorldKaraoke 화면 및 애창곡 데이터는 수정하지 않습니다.

## 검증

`npm ci && npm test`

`npm install --no-save --package-lock=false playwright@1.62.1` 및 WebKit 설치 후 `node tools/web-browser-check.cjs`로 Chromium/Android와 WebKit/iPhone 화면을 검사합니다. 브라우저 검사는 실제 카탈로그·서비스 워커로 검색 및 오프라인 실행을 확인하며, 음성 결과와 홈 화면 실행 상태는 모의 입력합니다. 실제 마이크·OS의 아이콘 생성·반주기 재생 검증을 대신하지 않습니다.

## 방별 QR 안내

`p2-room.html?room=1`부터 등록된 1·2·3·5·6·7·8번방을 지원합니다. QR 페이지의 버튼은 안드로이드 직접연결 앱 0.8 이상으로 방번호만 전달합니다. 기기명 대응표는 공개하지 않습니다. 실제 연결·권한·P2 인증은 기존 네이티브 앱에서 수행하며, 브라우저가 직접 반주기를 제어하는 기능은 아닙니다. 최초 연결 기록 설정이 필요한 휴대폰에는 직원 안내가 표시됩니다. iPhone에는 실행할 수 없는 연결 버튼을 표시하지 않습니다.

## 설치 파일 없는 바로가기

공통 주소: `https://cyberkjh36.github.io/neutinamu-song-search/?shortcut=1`. 이 모드는 WebAPK 설치 요청 없이 브라우저의 홈 화면 바로가기를 안내합니다. iPhone/iPad에는 Safari 공유 안내, Android에는 크롬/삼성 인터넷 안내를 표시합니다. 마지막 홈 화면 추가는 사용자가 직접 눌러야 합니다. 음성·키보드·초성 검색은 유지하며, 웹앱의 P2 직접 제어는 지원하지 않습니다. 이 바로가기가 방별 안드로이드 앱 연결 QR을 대체하거나 반주기 제어 기능을 추가하는 것은 아닙니다.
