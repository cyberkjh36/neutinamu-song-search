# WORLD KARAOKE · 휴대폰 음성검색 (WEB 2.3)

공유 주소: https://cyberkjh36.github.io/neutinamu-song-search/wk/

WEB 2.3: PC에서 검색 완료를 확인하면 검색 버튼이 **다음 곡 검색**으로 바뀝니다. 누르면 이전 검색어를 지우고 입력칸을 선택하며 PC 연결과 선택 언어는 유지합니다. 새 곡명을 입력하거나 말한 다음 **PC에서 검색**을 눌러야 전송됩니다. 직접 글자를 고치거나 새 음성이 인식되면 즉시 새 검색으로 전환합니다. 검색 실패 시에는 입력을 보존하여 재시도할 수 있습니다. 11개 언어에 적용했으며 PC 런처는 다시 받을 필요가 없습니다.

Android Chrome과 iPhone Safari에서 여는 웹 프로그램입니다. APK 설치나 Bluetooth 페어링은 필요 없습니다. PC 런처 **1.3.52 이상**과 PC·휴대폰의 인터넷 연결이 필요합니다.

1. PC에서 새 런처의 START.exe 실행 → 국기 선택 → 휴대폰 아이콘.
2. 휴대폰 카메라로 PC의 QR을 찍거나 위 주소를 열고 PC에 표시된 8자리 번호 입력.
3. 국기/언어 선택 → PC 연결 → 노래 제목 말하기.
4. 인식된 글자를 확인하고 **PC에서 검색** 누르기.
5. PC 검색 결과의 **＋ 예약**으로 곡을 추가합니다.

휴대폰 3대까지 연결됩니다. PC 검색 화면은 함께 사용하므로 마지막 검색이 표시됩니다. 앞선 검색은 PC 연결창의 최근 검색에서 다시 열 수 있습니다. PC 연결창을 닫거나 새 번호를 만들면 다시 연결해야 합니다. 연결번호는 최대 24시간 유지됩니다. 휴대폰 화면을 잠그거나 브라우저를 오래 뒤로 보내면 연결이 끊길 수 있습니다.

11개 언어: 한국어, ไทย, Filipino, Tiếng Việt, नेपाली, Монгол, Bahasa Indonesia, ລາວ, မြန်မာ, 中文, 日本語. 해당 언어로 UI를 표시하고 음성인식 언어를 지정합니다. 실제 음성인식 지원은 기기·브라우저·음성 서비스에 따라 다릅니다. 말하기가 작동하지 않으면 입력칸을 누른 뒤 휴대폰 키보드의 마이크를 사용하거나 직접 입력하세요. 말하기 버튼은 인식 결과만 입력하며 자동 검색하지 않습니다.

마이크 허용 요청은 말하기를 누를 때 발생합니다. 음성은 브라우저/운영체제의 음성 서비스에서 처리될 수 있습니다. 이 앱과 전달 서버는 녹음 파일을 받거나 저장하지 않습니다. 확인한 검색어와 언어만 HTTPS 서버를 통해 PC로 전달됩니다. 검색어는 PC의 처리 확인 후 서버에서 지워지며, PC 연결창의 최근 검색 목록은 창을 닫을 때 사라집니다.

GitHub Pages는 화면을 제공하고, 별도 HTTPS 서버가 검색어를 전달합니다. 서버 주소는 relay-client.mjs의 ENDPOINT에 있습니다. 번호를 아는 사람이 PC 검색을 요청할 수 있으므로 번호는 이용할 손님에게만 알려 주세요.

기존 저장소의 노래번호 검색 화면은 루트 주소에 유지합니다. /wk/는 별도 캐시 범위를 사용합니다.

검증: Node UI 이벤트/번역 검사, HTTPS 전달/인증/3대 제한/중복 방지 검사 및 PC 클라이언트 검사. 실제 Android·iPhone 마이크와 Windows UI 실기 검증은 별도로 필요합니다.

WEB 2.1: 브라우저 fetch의 호출 대상을 고정해 PC 연결 전 통신 오류를 수정했습니다. 연결 진행/실패는 PC 연결 버튼 아래에 표시합니다. 10초 응답 제한과 재시도를 지원합니다. PC 1.3.54는 QR 위 설명 높이를 자동 조절하고 새 웹 버전 주소를 QR에 넣습니다.

WEB 2.2: Android의 삼성 인터넷 등에서는 화면 맨 위에 **Google Chrome으로 열기** 버튼을 표시합니다. 버튼을 직접 누르면 Android Intent로 Chrome을 지정하여 같은 화면을 엽니다. 연결번호·선택 언어·입력한 곡명은 주소의 fragment로 전달되어 GitHub 요청에 포함되지 않습니다. 기존 연결은 해제하고 Chrome에서 PC 연결을 다시 누릅니다. 기존 8자리 QR은 그대로 사용할 수 있으며 PC 1.3.54를 다시 받을 필요가 없습니다.

Chrome과 iPhone Safari에서는 전환 안내를 숨깁니다. Chrome 실행을 확인하지 않고 성공했다고 표시하거나 자동으로 반복 실행하지 않습니다. Chrome이 없거나 브라우저가 실행을 막으면 설치/확인 링크와 기본 브라우저 안내를 사용하세요. QR을 처음 여는 앱은 휴대폰 설정 또는 QR 스캐너가 결정하며 웹페이지가 그 기본값을 바꿀 수는 없습니다. 삼성 휴대폰: 설정 → 애플리케이션 → 기본 앱 선택 → 브라우저 앱 → Chrome. 메뉴 이름은 기기 버전에 따라 다를 수 있습니다.

검증: 기존 연결/검색/11개 언어/캐시 검사와 Android 브라우저 구분, Chrome 전환 상태 전달, iPhone 유지 검사를 통과했습니다. 실제 Galaxy의 앱 전환과 마이크 사용은 별도 실기 확인이 필요합니다.
