# 느티나무노래방 전용 리모컨 설치파일

고정 설치 안내 주소: https://cyberkjh36.github.io/neutinamu-song-search/p2-install.html

현재 배포본은 **0.11.14 애창곡 바로 예약 버전**입니다.

- 애창곡 목록의 ‘곡 선택’을 **‘＋ 예약’**으로 바꿨습니다.
- 원하는 곡을 누르면 곡번호를 확인하고 기존 예약 명령을 한 번 보냅니다. 반주기가 처리하면 예약곡 목록 맨 뒤에 추가됩니다.
- 예약 요청 중에는 연속 누르기에 따른 중복 전송을 막습니다. 연결되지 않았거나 이전 요청 처리 중이면 안내하고 전송하지 않습니다.
- 현재 재생을 시작하거나 정지시키지 않습니다. 방 연결, 음성·초성 검색, 예약 순서, 예약 취소와 다음곡 실행은 기존 기능을 유지합니다.
- 30~40대·50~60대 애창곡과 트로트 베스트 각 50곡은 0.11.13과 같습니다. 추천 목록은 앱에 내장되어 있습니다.
- 추천곡은 2026년 10월 TJ미디어 공식 인기차트를 참고했습니다. 연령별 목록은 편집한 추천곡이며 연령별 공식 순위나 매장 실시간 집계는 아닙니다.

기존 앱을 삭제하지 않고 업데이트할 수 있습니다. 기존 설치 QR과 각 방 연결 QR도 그대로 사용합니다.

- 화면 검사에서 ‘＋ 예약’ 표시, 정확한 곡번호 전송, 연속 누르기, 연결 끊김, 이전 요청 처리 중, 닫기 취소와 기존 예약곡 목록 동작을 확인했습니다.
- 최종 APK의 서명, 방 대응표, 패키지, 방 QR 등록, 권한과 CI 결과물의 일치를 검사했습니다.
- 실제 휴대폰과 P2 반주기의 무선 연결·제어는 빌드 환경에서 직접 시험하지 않았습니다.

CI 기본 APK에는 매장 방 정보가 없으므로 그대로 배포하지 않습니다. 검증된 방 대응표를 포함한 뒤 기존 키로 서명하고 최종 파일을 검사합니다.

GitHub에서 설치파일을 제공합니다. 휴대폰과 브라우저의 다운로드·설치 확인은 그대로 적용됩니다. 설치가 끝나면 해당 방의 QR로 연결합니다. 아이폰에는 설치할 수 없습니다.
