0.11.10의 갤럭시 A16 · Android 16 호환 연결은 여전히 시험 기능입니다. 실제 P2의 연결 승인과 여러 휴대폰 동시 사용은 현장 확인이 필요합니다. 이번 변경은 중계기나 설치 없는 웹 리모컨 기능을 추가하지 않습니다.

0.11.10 APK는 방 정보가 누락된 버전이므로 설치하지 말고 0.11.11을 사용해 주세요. 이전 0.11.9의 백신 검사 결과를 이 버전의 검사 결과로 사용하지 않습니다.

GitHub에서 설치파일을 제공합니다. 휴대폰과 브라우저의 다운로드·설치 확인은 그대로 적용됩니다. 다운로드만으로 설치되거나 보안 설정이 변경되지 않습니다. 설치가 끝나면 해당 방의 QR로 연결합니다. 아이폰에는 설치할 수 없습니다.

원본 서명 키, 인증 기록, PCAP, 제3자 앱 및 별도의 방 설정 원본은 공개 소스에 추가하지 않습니다.
